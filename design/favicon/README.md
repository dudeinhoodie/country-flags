# Vexi favicon

Based on the continents-relief icon. PNG sizes: 16, 32, 48, 180, 192, 512.
favicon.ico contains 16×16, 32×32 and 48×48 images.
Small geographic details are decorative at favicon sizes.

Copy these files to your website's public root and add:

```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
```

The 192 and 512 PNGs are also available for a web app manifest.
